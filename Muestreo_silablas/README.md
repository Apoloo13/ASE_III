The following folder has the videos and data retrieved from 50 participants pronouncing syllables (RA, RE, RI, RO, RU, TA, TE, TI, TO, TU, SA, SE, SI, SO, SU). The code "orofacial_tracker.py" has the interface to retrieve the data from the participants using MediaPy. The "orofacial_analysis.py" can plot a single participant´s data or compare all participants and generate the mean trajectory. The "orofacial_time_panel.py" analyzes the data from another perspective, not only obtaining the mean trajectory, but also trying a different approach to prove the mean trajectory is obtained correctly.
